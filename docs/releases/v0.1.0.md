# PatchProof v0.1.0 — release notes draft

PatchProof's first release packages the existing local scan → evidence → export
→ fix → replay workflow. The CLI checks CSP/HSTS header presence and Secure on
explicitly named cookies. Portable CheckSpecs preserve detector semantics and
replay without AI; schema 1/2 specs remain supported alongside schema 3.

The optional API and dashboard add authenticated loopback access, SQLite history,
immutable original findings, restart recovery and recheck timelines. Optional
OpenRouter investigation uses bounded tools and sanitized evidence, retaining
baseline results when configuration or the provider is unavailable. Optional
Chromium scanning detects static HTTP resource references on HTTPS documents,
with a macOS egress sandbox and same-origin HTTPS broker.

This release does not assess policy strength, prove exploitability, authenticate,
crawl, run application JavaScript, or offer public hosting/multi-user access.
Browser scanning is unavailable on Linux/Windows. API storage uses `fcntl` and is
not supported on native Windows. SQLite is local and unencrypted; reports retain
target paths and configured cookie names. Avoid secrets in those inputs.

Installation and controlled demos: [README](../../README.md).
Verification and exact tested environments: [acceptance record](verification-0.1.0.md).
Artifacts: local `dist/patchproof-0.1.0-py3-none-any.whl`,
`dist/patchproof-0.1.0.tar.gz`, and `dist/SHA256SUMS`. The wheel contains Python
runtime resources and inline migration code; dashboard sources are in the sdist
and repository and require their own npm build.
